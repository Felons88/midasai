# AGENT_HANDOFF.md

Before starting work:

1. Pull latest GitHub changes.
2. Read CLAUDE.md.
3. Read PROJECT_CONTEXT.md.
4. Read memory/project-state.md.
5. Read latest checkpoint files.

Do not repeat completed work.

Do not perform a new repository audit unless requested.

Continue from current sprint.

When finishing:

1. Update project-state.md.
2. Create checkpoint.
3. Commit changes.
4. Push to GitHub.

GitHub is the source of truth.

Local workspace state should never be assumed.
